# Time Tracker

> Track time, projects, and reports with a clean .NET + React stack.

## 🚀 Overview

Time Tracker 3.0 is a full-stack application for managing projects and tracking work time.  
Built with **.NET 8 (API, Application, Domain, Infrastructure)** on the backend and **React + Vite** on the frontend.  
Designed with clean architecture, code quality tools, and CI/CD pipelines for reliable deployments.

## ✨ Features

- Project & time entry management
- Reporting with CSV export
- Authentication & authorization (JWT + Identity)
- Clean architecture with EF Core
- Frontend built with React (Vite, React Query, React Hook Form)
- Deployment ready for Azure (App Service, Static Web Apps, SQL, Key Vault)

## 🛠 Tech Stack

- **Backend:** .NET 8, EF Core, Identity, Serilog
- **Frontend:** React, Vite, React Query, React Hook Form, Zod
- **DevOps:** GitHub Actions, Azure App Service, Azure SWA
- **Code Quality:** ESLint, Prettier, Husky, Conventional Commits
